# FloorScore - legal pages

Public privacy policy and terms of service for the FloorScore Shopify app,
served via GitHub Pages so the URLs stay reachable independently of the app's
own hosting.

The app renders the same text at `/legal/privacy` and `/legal/terms`; if you
change one, change the other. The source of truth is
`app/routes/legal.privacy.tsx` and `app/routes/legal.terms.tsx` in the app repo.

This repository is public **only** because GitHub Pages requires it. It contains
no application code.
